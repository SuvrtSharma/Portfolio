Graph algorithms are hard to *feel* from pseudocode. This project makes them
visible: you watch the search spread across a grid and see, frame by frame, why
one algorithm beats another.

## Watching the search think

The visualizer animates three classic traversals — **Dijkstra**, **A-star**, and
**BFS** — as they explore nodes and update the shortest path in real time. Seeing
A-star's heuristic pull it straight toward the goal, while BFS fans out evenly,
teaches the difference far better than a complexity table.

## Why build it

- **Real-time exploration** — every visited node and path update is animated.
- **Side-by-side comparison** — run the algorithms on the same grid and watch
  their efficiency diverge.
- **Intuition over memorisation** — the point is to *understand* graph traversal,
  not recite it.

A small, fun project — and a genuinely good way to internalise how these
algorithms actually behave.
